Sabor Local — Atividade 01 | FlutterFlow
📌 Sobre o projeto
O projeto Sabor Local foi desenvolvido como parte da atividade acadêmica da disciplina de Desenvolvimento, utilizando a plataforma FlutterFlow.

A atividade teve como objetivo colocar em prática os conhecimentos relacionados à criação de interfaces, organização de widgets, criação de múltiplas páginas, navegação entre telas, validação de campos, utilização de Actions, gerenciamento de estado e documentação do projeto.

O aplicativo foi desenvolvido com a temática de um restaurante de comida mineira, utilizando uma identidade visual própria para o projeto.

🎯 Objetivo da atividade
A atividade tem como objetivo desenvolver uma aplicação utilizando o FlutterFlow, colocando em prática os seguintes conhecimentos:

Familiarização com a plataforma FlutterFlow;
Navegação pelo painel;
Utilização do UI Builder;
Organização da Widget Tree;
Utilização de componentes;
Criação de layouts;
Utilização de Row, Column e Stack;
Configuração de cores, fontes, bordas e espaçamentos;
Criação de múltiplas páginas;
Navegação entre telas;
Utilização de variáveis;
Criação de interações;
Validação de campos;
Utilização de Actions;
Criação de documentação.
